02
УСТАНОВИ OPENCLAW
Одна команда — устанавливает OpenClaw глобально через npm.
Terminal.app
$ npm install -g openclaw@latest added 847 packages in 23s + openclaw@2026.2.6 # Проверяем установку: $ openclaw --version openclaw/2026.2.6 darwin-arm64 node-v22.13.1
!!!
Если после установки команда openclaw не находится — проблема с PATH. Добавь в ~/.zshrc:
export PATH="$(npm prefix -g)/bin:$PATH"
Затем: source ~/.zshrc
M-CHIP
На Apple Silicon при ошибках компиляции native модулей:
SHARP_IGNORE_GLOBAL_LIBVIPS=1 npm install -g openclaw@latest
Также убедись что установлен Xcode CLI Tools: xcode-select --install

WSL2
OpenClaw не поддерживает нативный Windows. WhatsApp Web протокол, iMessage и Unix process management требуют POSIX-окружения. Официальный путь — WSL2 (Windows Subsystem for Linux). После установки WSL2 следуй Linux-инструкциям — всё работает одинаково хорошо.
01
УСТАНОВИ WSL2
Открой PowerShell от имени Администратора и выполни:
PowerShell (Admin)
PS> wsl --install Installing: Windows Subsystem for Linux Installing: Ubuntu The requested operation is successful. Please restart your computer to continue setup. # Перезагрузи ПК. После перезагрузки откроется Ubuntu: Enter new UNIX username: myuser New password: **** Installation complete! # Проверить версию WSL: PS> wsl --status Default Version: 2
02
УСТАНОВИ NODE.JS 22 В WSL2
Открой Ubuntu (WSL2) и выполни — рекомендуем nvm для управления версиями Node:
Ubuntu (WSL2)
# Обновляем пакеты: $ sudo apt update && sudo apt upgrade -y # Устанавливаем nvm: $ curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash $ source ~/.bashrc # Устанавливаем Node 22: $ nvm install 22 && nvm use 22 Now using node v22.13.1 (npm v10.9.2) $ node --version v22.13.1
PERF
Храни файлы OpenClaw внутри WSL файловой системы (/home/username/), а не на Windows дисках (/mnt/c/). Кросс-системный доступ к файлам работает в 10-20x медленнее.

SYSD
Некоторые дистрибутивы WSL2 не включают systemd по умолчанию. Проверь:
systemctl --user status openclaw-gateway
Если не работает, добавь в /etc/wsl.conf:
[boot]
systemd=true
Затем перезапусти WSL: wsl --shutdown

ЗАПУСТИ ОНБОРДИНГ
На VPS онбординг запускается в headless режиме. Заранее подготовь API ключи.
VPS — onboarding
$ openclaw onboard --install-daemon [1] API key (Anthropic/OpenAI): sk-ant-... [2] Model: claude-sonnet-4-5 [3] Telegram token: 123456:ABC... [4] Gateway bind: Local (127.0.0.1) ← выбирай LOCAL на VPS! ✓ systemd service installed ✓ Gateway started → ws://127.0.0.1:18789
!!!
При выборе bind — выбирай Local (127.0.0.1), НЕ 0.0.0.0. Это критичная настройка безопасности для VPS. Проверь после:
netstat -an | grep 18789 | grep LISTEN
Должно быть 127.0.0.1:18789, а не 0.0.0.0:18789

$ sudo ufw default deny incoming $ sudo ufw default allow outgoing $ sudo ufw allow 22/tcp $ sudo ufw limit 22/tcp ← rate limit SSH $ sudo ufw enable $ sudo ufw status numbered [ 1] 22/tcp ALLOW IN Anywhere (limit) [ 2] Outgoing ALLOW OUT Anywhere
:22/tcp

:80/:443
HTTP/S если нужен Nginx

ОПЦИОНАЛЬНО: DOCKER DEPLOY
Для максимальной изоляции на production VPS — Docker Compose конфиг:
docker-compose.yml
version: '3.8'
services:
  openclaw:
    image: openclaw/openclaw:latest
    container_name: openclaw-gateway
    restart: unless-stopped
    ports:
      - "127.0.0.1:18789:18789"  ← только localhost!
    volumes:
      - ~/.openclaw:/root/.openclaw
    environment:
      - ANTHROPIC_API_KEY=${ANTHROPIC_API_KEY}
      - TELEGRAM_BOT_TOKEN=${TELEGRAM_BOT_TOKEN}
    deploy:
      resources:
        limits:
          memory: 512m  ← лимит RAM
          cpus: '1'
# Запуск:
docker compose up -d
→ openclaw-gateway started

# Обновление:
docker compose pull && docker compose up -d

02
БАЗОВЫЙ КОНФИГ (~/.openclaw/openclaw.json)

Минимальный конфиг для запуска с Telegram:

openclaw.json
{
  // Идентичность бота:
  identity: {
    name: "MyBot",
    emoji: "🤖",
  },

  // API ключи через переменные окружения (безопаснее):
  env: {
    vars: {
      ANTHROPIC_API_KEY: "sk-ant-...",
    },
  },

  // Агент:
  agents: {
    defaults: {
      model: { primary: "anthropic/claude-sonnet-4-5" },
    },
  },

  // Telegram канал:
  channels: {
    telegram: {
      botToken: "${TELEGRAM_BOT_TOKEN}",
      dmPolicy: "pairing",     // незнакомцы получат код подтверждения
      groups: {
        "*": { requireMention: true },  // в группах нужен @mention
      },
    },
  },
}
!!!
Строгая валидация схемы! Неизвестные ключи или неверные типы = Gateway не запустится. При ошибках запускай: openclaw doctor --fix
